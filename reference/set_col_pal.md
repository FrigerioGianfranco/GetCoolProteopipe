# Set the col_pal option.

It sets the option GetCoolProteopipe.col_pal, so it will be consistently
applied to all the functions that have the col_pal argument.

## Usage

``` r
set_col_pal(col_pal = NULL)
```

## Arguments

- col_pal:

  NULL or a character vector with colors. The option
  GetCoolProteopipe.col_pal will be set to it.

## Value

Nothing. It only sets the GetCoolProteopipe.col_pal option.

## Examples

``` r
if (FALSE) { # \dontrun{

set_col_pal(c(S = "green", V = "orange"))

} # }


```
