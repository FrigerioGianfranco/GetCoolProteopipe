# Set the log_base option.

It sets the option GetCoolProteopipe.log_base, so it will be
consistently applied to all the functions that have the base or log_base
argument.

## Usage

``` r
set_log_base(log_base = 2)
```

## Arguments

- log_base:

  NULL or a number. The option GetCoolProteopipe.log_base will be set to
  it.

## Value

Nothing. It only sets the GetCoolProteopipe.log_base option.

## Examples

``` r
if (FALSE) { # \dontrun{

set_log_base(2)

} # }

```
